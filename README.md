# Chomsky Normal Form

Программа для преобразования контекстно-свободной грамматики в нормальную форму Хомского (НФХ).

## Описание

Программа принимает контекстно-свободную грамматику и последовательно преобразует её в нормальную форму Хомского.

Ввод грамматики выполняется построчно. Каждое правило записывается в формате:

```text
S -> aAB | bA | ε
A -> aAB | ε
B -> bB | c
```

Пустая строка завершает ввод.

## Этапы преобразования

1. **Удаление ε-продукций** — исключение правил, порождающих пустую строку, с сохранением возможности вывести ε из нового стартового символа.
2. **Удаление цепных правил** — устранение правил вида `A -> B`, где `A` и `B` — нетерминалы.
3. **Удаление бесполезных символов**:
   - удаление непорождающих символов;
   - удаление недостижимых символов.
4. **Замена терминалов в длинных правых частях** — терминалы внутри длинных правил заменяются новыми нетерминалами.
5. **Бинаризация правил** — длинные правые части разбиваются так, чтобы в каждом правиле оставалось не более двух нетерминалов.

## Формат нормальной формы Хомского

После преобразования правила имеют один из следующих видов:

```text
A -> BC
A -> a
```

где `A`, `B`, `C` — нетерминалы, а `a` — терминал.

Также допускается специальное правило стартового символа:

```text
S0 -> ε
```

если исходная грамматика порождает пустое слово.

## Используемые технологии

- Java
- IntelliJ IDEA

## Запуск

1. Откройте проект в IntelliJ IDEA.
2. Запустите класс `Main`.
3. Введите правила грамматики построчно.
4. Для завершения ввода оставьте строку пустой.

## Пример

Входная грамматика:

```text
S -> aAB | bA | ε
A -> aAB | ε
B -> bB | c
```

Программа выводит результаты промежуточных этапов преобразования и итоговую грамматику в НФХ.

## Назначение

Проект предназначен для изучения контекстно-свободных грамматик и алгоритма преобразования грамматики в нормальную форму Хомского.
